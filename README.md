## Featured project

### [Kraken Policy Assistant](https://github.com/Andre-Edwards/MSc-Kraken-RAG-Submission)

A dissertation prototype for answering questions over public policy documents, with source citations and inspectable evidence.

- **Built with:** Python, FastAPI, React, TypeScript, ChromaDB and SQLite.
- **Research:** Compared fixed-size, structure-aware and hybrid retrieval on labelled questions.
- **Result:** Hybrid retrieval achieved source-level macro F1@5 of **0.889**, compared with **0.813** for the fixed-size baseline on 59 questions. This measures retrieval quality, not answer accuracy.
- **Explore:** [Code walkthrough](https://github.com/Andre-Edwards/MSc-Kraken-RAG-Submission/blob/main/PORTFOLIO.md) · [Reproduction guide](https://github.com/Andre-Edwards/MSc-Kraken-RAG-Submission/blob/main/REPRODUCIBILITY.md) · [Evaluation method](https://github.com/Andre-Edwards/MSc-Kraken-RAG-Submission/tree/main/backend/evaluation)
